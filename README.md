# NSE LTP Calculator + Options Intelligence Platform

A free-first NSE market-data and options-intelligence platform: LTP calculator, option chain analytics, historical data/charts, AI-assisted explanations, watchlists/alerts, and a future Premium SaaS layer.

Inspired by the useful functionality of public competitor tools (ltpcalculator.com, niftytrader.in and similar), but built independently — no copied code, branding, text, or design.

## Project status

Currently in **Phase 0 — Product Blueprint + Competitor Analysis**. No application code has been written yet; this phase produces the planning documents that every later phase builds on.

See [`docs/phase-0/README.md`](docs/phase-0/README.md) for the full Phase 0 deliverable set, and [`docs/ROADMAP.md`](docs/ROADMAP.md) for the phase-by-phase build plan.

## Development approach

The project is built in sequential phases (see `docs/ROADMAP.md`). Each phase is implemented, tested, reviewed and documented before the next one starts — the product is not built as a single large implementation.

## Important legal note

This project will not scrape NSE's website for production data. Before any live market-data feature is built, a licensed data-provider decision is required (see [`docs/phase-0/11-risks-and-assumptions.md`](docs/phase-0/11-risks-and-assumptions.md)).
