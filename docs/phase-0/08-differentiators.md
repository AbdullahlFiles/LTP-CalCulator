# Product Differentiators

Relative to the three reference competitors (see `02-competitor-matrix.md`):

1. **Transparent data lineage.** Every number on screen is traceable: raw data → named deterministic calculation → (optional) rule-based tag → (optional) AI interpretation, with each layer visually distinct. Competitors present proprietary-named signals ("Magical Lines", "iDaddy Blast") without exposing method or inputs; we do the opposite.
2. **Honest uncertainty.** AI and rule-based interpretations never use guaranteed/predictive language. This is a constraint competitors visibly don't share (one advertises "AI-Powered Accuracy Tracking" as a marketing feature).
3. **Adaptive complexity in one tool.** Beginner / Advanced / Power-user modes on the *same* option chain, rather than a separate simplified product and a separate "pro" product, or a single dense table that overwhelms beginners.
4. **Free tier that stays useful forever.** The free/premium boundary is drawn at depth and scale (history, AI volume, screeners), not at core functionality — explicitly required by the spec and not a stated policy of any reference competitor.
5. **SEO-integrated education, not a bolt-on blog.** Educational content links directly into the live tool with the same instrument/context pre-loaded (see journey J1), turning search traffic into tool usage rather than isolated content pageviews.
6. **Engineering quality as a user-facing feature.** Explicit loading/error/empty/stale-data states, accessibility, and performance on large real-time tables (virtualization) — categories competitor products in this space are not generally known for.
7. **Swappable infrastructure.** Market-data provider and AI provider are both abstracted from day one, so a provider outage, price change, or licensing change doesn't threaten the whole product — an internal quality attribute that shows up externally as reliability.
